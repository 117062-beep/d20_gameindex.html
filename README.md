# あつまれ！柴犬の島 — 完全版

柴犬を動かし、着替えや敵・ボスとのバトルを楽しむブラウザーゲームです。

## 起動

リポジトリをダウンロードし、`index.html` をブラウザーで開いてください。画面装飾をCDNから読み込むため、インターネット接続が必要です。

ゲーム本体は `index.html` です。これまでの `game3` を、ブラウザーがHTMLとして開ける名前に変更しました。READMEは遊び方の説明に使用します。

## 操作

- 移動：矢印キー／WASD、または画面の方向ボタン。
- 攻撃：Space、または「ほえる」ボタン。
- 着替え：「きせかえ」から毛色・アクセサリを選びます。

公開用サービスの設定はこのリポジトリの管理者が行ってください。この変更ではサイトの公開・設定変更は行っていません。
